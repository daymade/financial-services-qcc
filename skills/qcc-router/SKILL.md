# 企查查技能路由

本 Skill 只选择现有的企查查业务 Skill，不代替它们采集数据或生成报告。仅当用户明确指定企查查，或项目已有明确的 QCC 数据通道时进入。普通公司研究、网页搜索和泛泛的「做尽调」不自动切换到企查查 MCP。

1. 在当前宿主运行 `python3 <本 Skill 目录>/scripts/catalog.py list`，读取已安装 Skill 的名称和简要说明。目录由脚本从 `~/.claude/skills` 读取；若实际安装在别处，传入绝对路径 `--root`。不要把仓库里存在、但宿主没有安装的目录当成可用能力。
2. 按用户要的**结果**选择一项。企业主体核验通常是 `kyb-verification-qcc`；投资委员会备忘录是 `ic-memo-qcc`；诉讼、信用、知识产权、融资和竞品各有独立 Skill。名称相近时读候选的简要说明，必要时只比较两份候选的前言。一个请求确实跨多个结果时，按阶段选择，不在开工时加载全部 22 份正文。
3. 运行 `python3 <本 Skill 目录>/scripts/catalog.py resolve <选中目录名>`，读返回的 `SKILL.md` **全文**，再按该 Skill 的要求加载参考资料、核实企查查 MCP 与授权范围。已设为手动调用的子 Skill 仍是可读文件；不要通过模型的 Skill 工具调用被隐藏的子项。

目录是运行时清单，不是写死的 22 项快照。找不到精确子项或目录有损坏时停止并报出路径，不猜同名能力。保留每个 `/子 Skill 名` 手动入口；Router 不修改、删除或复制子 Skill 的业务方法，也不读取或写入 MCP 凭据。
